## About the Project 🌟

This project demonstrates a basic video streaming pipeline. It allows users to upload video files, which are then processed on the server-side using FFmpeg to convert them into HLS (HTTP Live Streaming) format. The HLS streams are then served and can be played by a React-based frontend using the `video.js` player.

## Features ✨

- **Video Upload:** Users can upload video files through a web interface.
- **HLS Transcoding:** Server-side processing converts uploaded videos into HLS format for adaptive streaming.
- **Adaptive Streaming:** Delivers video content efficiently with varying bitrates.
- **Video Playback:** Integrated video player in the frontend to stream HLS content.
- **API Endpoints:** Provides API endpoints for video upload and retrieval.

## Tech Stack 💻

- **Backend:** JavaScript, Node.js, Express.js, Multer, CORS, FFmpeg (via `child_process`)
- **Frontend:** JavaScript, React, Vite, Video.js, HTML, CSS
- **Configuration:** ESLint, Prettier (implied by ESLint config)

## Installation 📦

This project requires Node.js and npm (or yarn) to be installed.

### Backend Setup

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/abhishek2k4/video-streaming-poc.git
    cd video-streaming-poc
    ```

2.  **Install backend dependencies:**
    ```bash
    npm install
    ```

3.  **Ensure FFmpeg is installed:**
    This project relies on FFmpeg for video transcoding. If you don't have it installed, follow the instructions for your operating system:
    -   **macOS:** `brew install ffmpeg`
    -   **Debian/Ubuntu:** `sudo apt update && sudo apt install ffmpeg`
    -   **Windows:** Download from the [official FFmpeg website](https://ffmpeg.org/download.html) and add it to your system's PATH.

### Frontend Setup

1.  **Navigate to the frontend directory:**
    ```bash
    cd frontend
    ```

2.  **Install frontend dependencies:**
    ```bash
    npm install
    ```

## Usage ▶️

### Running the Application

1.  **Start the backend server:**
    Open your terminal, navigate to the root directory of the project (`video-streaming-poc`), and run:
    ```bash
    npm run start
    ```
    The backend server will start on `http://localhost:8000`.

2.  **Start the frontend development server:**
    Open a *new* terminal, navigate to the `frontend` directory, and run:
    ```bash
    npm run dev
    ```
    The frontend application will start on `http://localhost:3000` (or another port if 3000 is in use).

### Uploading and Streaming Videos

1.  Open the frontend application in your browser (e.g., `http://localhost:3000`).
2.  You should see a video player interface.
3.  Use the upload functionality (if exposed via UI, otherwise programmatically via API) to upload a video file.
4.  Once uploaded and processed, the video will be available for streaming via the HLS link generated by the backend.

**Example of Backend Upload API Call:**

This is a `POST` request to the `/upload` endpoint on your backend server.

```bash
curl -X POST -F "file=@/path/to/your/video.mp4" http://localhost:8000/upload
```

This will return a JSON response containing the `videoUrl` for the HLS stream:

```json
{
  "message": "Video converted to hls format",
  "videoUrl": "http://localhost:8000/uploads/courses/{lessonId}/index.m3u8",
  "lessonId": "{lessonId}"
}
```

This `videoUrl` can then be used in the frontend `VideoPlayer` component.

## API Reference 🔗

### `POST /upload`

Uploads a video file and converts it to HLS format.

-   **Request Body:** `multipart/form-data` with a field named `file` containing the video file.
-   **Success Response:**
    ```json
    {
      "message": "Video converted to hls format",
      "videoUrl": "http://localhost:8000/uploads/courses/{lessonId}/index.m3u8",
      "lessonId": "{lessonId}"
    }
    ```
-   **Error Response:**
    Standard Express error responses.

### `GET /uploads/(path)`

Serves static files from the `uploads` directory, including HLS playlists and segments.
